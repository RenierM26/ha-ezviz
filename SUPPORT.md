# Getting help

This repository owns the custom **Ezviz(Beta)** / `ezviz_cloud` integration,
not Home Assistant's built-in **EZVIZ** integration.

- [Setup](docs/setup.md), [upgrading and rollback](docs/upgrading.md),
  [troubleshooting](docs/troubleshooting.md).
- [Report a bug, request device support or suggest a feature](https://github.com/RenierM26/ha-ezviz/issues/new/choose).
- For a security vulnerability, use [private reporting](SECURITY.md), not an issue.

Give the installed tag or exact main commit, HA version, model/firmware and
owner/shared-account role. Describe the exact failed action, expected/observed
behavior and whether it recovered; distinguish HA state from physical outcomes.
Review the complete diagnostics download, HA envelope/filename and minimal log
excerpts before sharing. Do not attach secrets, serials or signed/private URLs.

A diagnostics download uses cached state; do not repeatedly wake/reboot hardware,
reset credentials or delete storage merely to produce a report. Model support
may require an owner to test a candidate safely. Inactivity is not grounds for
automatic issue closure; this repository does not use a stale-issue closer.
